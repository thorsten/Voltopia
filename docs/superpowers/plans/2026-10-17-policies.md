# Policies / Ordinances Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four city-wide ordinances (rooftop-PV mandate, night tariff, speed limit, smart-meter mandate) as toggles with a daily cost, a happiness term and one sim effect each, surfaced in the HUD console, the budget, the save game and the agent tools.

**Architecture:** One registry in `src/sim/policies.ts` (ids re-exported from `src/shared/types.ts`, parameters in `BALANCE.policies`) holds `state.policies` and exposes accessor functions. Affected modules (growth, energy, inspect, vehicles, islandBalance, smartMeters, happiness) call the accessors instead of `BALANCE`, so an inactive policy returns exactly today's value. A `policiesStep` books the admin cost per tick into a new budget line. One command `setPolicy`, one stats block, one UI block, one agent tool.

**Tech Stack:** TypeScript strict, vitest, React 19, i18n in `src/ui/i18n.tsx`, Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-17-policies-design.md`

## Global Constraints

- `src/sim/` has no DOM or three.js imports; all randomness via `state.rng`; `src/shared/` never imports from `src/sim/`.
- No magic numbers in sim code: every policy parameter lives in `BALANCE.policies.<id>`.
- Every accessor returns the plain `BALANCE` value while its policy is off, so existing tests and balance stay unchanged.
- `SaveGame` stays backward compatible: `policies?` and `layers.pvMandated?` optional, `SAVE_VERSION` unchanged; absent means all off / no bits; unknown ids ignored.
- Every user-visible string in `src/ui/i18n.tsx`, English AND German.
- React effects depend on stable identities (`bridge.send`), never the `bridge` object.
- New sim command → agent tool + `docs/agent-tools.md`.
- Keep any single test under ~15 s; `pnpm format` before commits; hook (`typecheck && lint && format:check && test`) must be green; never `--no-verify`.

## Review Focus

1. An old autosave without `policies`/`pvMandated` must load as all-off with zero bits and identical behaviour. Test in Task 1 and Task 2.
2. Switching the PV mandate off must keep panels on buildings built under it; switching it on must not retro-fit existing buildings. Test in Task 2.
3. A non-smart car below the charge floor must still charge at noon under the night tariff, or it strands. Test in Task 3.
4. The speed limit must not slow buses, vans or trains (only commuter cars), or transit balance shifts silently. Test in Task 4.
5. The smart-meter mandate's happiness term must vanish at full coverage, or a finished rollout keeps punishing the city. Test in Task 1.

```ts
// src/sim/policies.ts
import { BALANCE, TICKS_PER_DAY } from '../shared/constants.ts';
import { POLICY_IDS, type PolicyId } from '../shared/types.ts';
import { meteredCoverage } from './smartMeters.ts';
import type { SimState } from './state.ts';

export { POLICY_IDS, type PolicyId };

export function defaultPolicies(): Record<PolicyId, boolean> {
  return {
    rooftopPvMandate: false,
    nightTariff: false,
    speedLimit: false,
    smartMeterMandate: false,
  };
}

export function policyActive(state: SimState, id: PolicyId): boolean {
  return state.policies[id];
}

/** Administration cost of the active ordinances per in-game day. */
export function policyDailyCost(state: SimState): number {
  let total = 0;
  for (const id of POLICY_IDS) if (state.policies[id]) total += BALANCE.policies[id].dailyCost;
  return total;
}

/**
 * Happiness term of the active ordinances. The smart-meter mandate only
 * weighs while meters are still being forced on households.
 */
export function policyHappiness(state: SimState): number {
  let total = 0;
  for (const id of POLICY_IDS) {
    if (!state.policies[id]) continue;
    if (id === 'smartMeterMandate' && meteredCoverage(state) >= 1) continue;
    total += BALANCE.policies[id].happiness;
  }
  return total;
}

/**
 * Charge this tick's administration cost and whatever subsidies the
 * growth step booked into `lastPolicySubsidy` since the last tick.
 */
export function policiesStep(state: SimState): void {
  const admin = policyDailyCost(state) / TICKS_PER_DAY;
  const spent = admin + state.lastPolicySubsidy;
  state.money -= spent;
  state.lastPolicyCost = spent;
  state.lastPolicySubsidy = 0;
  if (spent > 0) state.statsDirty = true;
}
```

/** Rooftop PV peak of the building on `index`: density table, or the mandate's density-1 panels. */
export function rooftopPeakAt(state: SimState, index: number): number {
  const density = state.layers.density[index];
  const table = BALANCE.energy.rooftopSolarPeakByDensity[density] ?? 0;
  if (density === 1 && state.layers.pvMandated[index] === 1) {
    return Math.max(table, BALANCE.policies.rooftopPvMandate.mandatePeakDensity1);
  }
  return table;
}

/** Growth calls this when a building spawns (density 0 → 1). */
export function onBuildingSpawned(state: SimState, index: number): void {
  if (!state.policies.rooftopPvMandate) return;
  state.layers.pvMandated[index] = 1;
  state.lastPolicySubsidy += BALANCE.policies.rooftopPvMandate.subsidyPerBuilding;
}

import { TICKS_PER_DAY } from '../shared/constants.ts';

function hourOfTick(tick: number): number {
  return ((tick % TICKS_PER_DAY) / TICKS_PER_DAY) * 24;
}

/**
 * May a car parked at home plug in now? Smart cars follow the surplus
 * gate in vehicles.ts regardless; under the night tariff a plain car
 * waits for the cheap hours unless it is nearly empty.
 */
export function homeChargingAllowed(
  state: SimState,
  smart: boolean,
  charge: number,
  tick: number,
): boolean {
  if (smart || !state.policies.nightTariff) return true;
  if (charge < BALANCE.vehicles.smartChargeFloor) return true;
  const { nightStartHour, nightEndHour } = BALANCE.policies.nightTariff;
