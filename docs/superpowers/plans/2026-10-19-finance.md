# Finance Implementation Plan

> **For agentic workers:** Execute task by task, in order. Steps use checkbox (`- [ ]`) syntax. Each task ends with a green pre-commit hook and one commit.

**Goal:** Loans and bonds with fixed interest, overdraft interest and a credit rating A–D, a renewable investment grant from an annual pot, and a grid fee slider — surfaced in the budget panel, the HUD console, the save game, scenarios and the agent tools.

**Architecture:** One module `src/sim/finance.ts` with `BALANCE.finance` and `SimState.finance`. `financeStep` runs once per tick after `repairStep` (so the day's operating income is complete) and books debt service, overdraft interest and grid-fee income; at each day rollover it pushes the day's operating income into a trailing window and recomputes the rating. `placePlant` charges the net price from `plantPrice()`. Commands `takeCredit`, `repayCredit`, `setGridFee`. With no credit, money ≥ 0 and grid fee 0, every number except plant prices equals today's.

**Tech Stack:** TypeScript strict, vitest, React 19, i18n in `src/ui/i18n.tsx`, Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-19-finance-design.md`

## Global Constraints

- `src/sim/` has no DOM or three.js imports; `src/shared/` never imports from `src/sim/`. No randomness needed here.
- No magic numbers in sim code: every finance figure lives in `BALANCE.finance`.
- Year length: `DAYS_PER_YEAR = SEASON_ORDER.length * DAYS_PER_SEASON` (20). Export it from `src/shared/constants.ts` if no such constant exists yet; per-tick rate = `ratePerYear / (DAYS_PER_YEAR * TICKS_PER_DAY)`.
- The grant year is `state.season.year` (already maintained by `seasonState`).
- `SaveGame.finance?` optional, `SAVE_VERSION` unchanged; absent → `defaultFinance()`. Values from a save are sanitised (finite numbers, known kinds, rating in A–D, gridFee clamped).
- Every user-visible string in `src/ui/i18n.tsx`, English AND German.
- React effects depend on stable identities (`bridge.send`), never the `bridge` object.
- New sim commands → agent tools + `docs/agent-tools.md`.
- Per-tick cost: skip the credit loop when there are no credits and `money >= 0`; grid-fee income only when `gridFee > 0`.
- Keep any single test under ~15 s; `pnpm format` before commits; hook must be green; never `--no-verify`.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. An old save without `finance` loads debt-free at rating A with grid fee 0 and identical behaviour (Task 1).
2. Debt service is never skipped: payments drive money negative, then overdraft interest applies (Task 1).
3. Undo of a granted plant refunds exactly the net price paid and returns the grant to the pot; pot resets on a new year only (Task 2).
4. Grid fee 0 and no credit → `happinessStep` and the budget net are unchanged (Task 3).
5. Scenario `money` conditions measure net worth, so a loan cannot win them (Task 4).

**`src/sim/finance.ts` exports:**

```ts
export function defaultFinance(): SimState['finance'];
export function totalDebt(state: SimState): number;
export function averageDailyIncome(state: SimState): number; // sum of incomeWindow / windowDays (Task 7: unplayed days count 0)
export function debtCap(state: SimState): number; // debtCapDays * max(avg, minIncomeBase)
export function creditRate(state: SimState, kind: CreditKind): number | null; // null at D
export function creditOfferRejection(state, kind, amount): string | null;
//   'creditRefused' (D) | 'invalidAmount' | 'creditLimit' (count or cap)
export function takeCredit(state, kind, amount): BuildResult;
export function repayCredit(state, id): BuildResult; // 'unknownCredit' | 'notRepayable' | 'notEnoughMoney'
export function computeRating(state): Rating;
export function financeStep(state: SimState, operatingNet: number): void;
```

`SimState.finance` = `FinanceSave` plus transient `dayIncome: number`. `SimState.lastFinance = { interest, principal, overdraftInterest, gridFeeIncome }` (all 0 by default).

`financeStep(state, operatingNet)`:

1. `gridFeeIncome` (Task 3 fills it in; 0 here) → `money += gridFeeIncome`.
2. For each credit (skip when none): `interest = outstanding * perTick(rate)`; loans pay `min(outstanding, principal / termTicks)`, and on the last tick (`tick - startTick >= termTicks`) the remaining outstanding; bonds pay principal only at maturity. Subtract from money, reduce outstanding, drop credits at ≤ 1e-9.
3. If `money < 0`: `overdraftInterest = -money * perTick(overdraftRatePerYear)`; subtract.
4. `dayIncome += operatingNet + gridFeeIncome`.
5. On day rollover (`state.tick % TICKS_PER_DAY === 0`): push `dayIncome` into `incomeWindow` (cap at `windowDays`), reset; `overdraftDays = money < 0 ? overdraftDays + 1 : 0`; `rating = computeRating(state)`; `statsDirty = true`.
6. Write `lastFinance`; `statsDirty = true` if any figure is non-zero.

`tick.ts`: extract the current `net` expression from `buildBudget` into `export function operatingNet(state): number` and call `financeStep(state, operatingNet(state))` right after `repairStep(state)`. `buildBudget` adds `gridFees`, `interest` (credit + overdraft), `repayment`; `net` becomes `operatingNet + gridFees - interest` (repayment is cash flow, not in net).

**Steps:**

```ts

//   SolarFarm, WindTurbine, RunOfRiver, TidalPlant, GeothermalPlant: 0.3
//   Battery, PumpedStorage: 0.2   (biogas and everything else: absent = 0)
```

- Move the cost computation of `placePlant` (multiplier + felling) into `plantPrice`; `grant = min(round(base * multiplier * share), grantRemaining)` — felling is never granted.

- `undoLastAction`: `if (entry.grantDelta) state.finance.grantUsedThisYear = max(0, used - grantDelta)`.
- `financeStep` calls `rollGrantYear` on day rollover; `plantPrice` also calls it (so a build on the first tick of a year sees the fresh pot).

## Self-review notes

- Interest is simple per tick on the outstanding amount; a loan's interest total is therefore ~half of `principal × rate × term`. Tests assert that.
- `operatingNet` is shared between `buildBudget` and `financeStep`, so the rating's income measure and the panel's net never disagree.
- The grant changes plant prices from day one — the only deliberate deviation from "inactive = unchanged"; scenarios with tight starting money get slightly easier, which Task 7 checks on the scenario defs (`defs.test.ts` determinism still holds).
